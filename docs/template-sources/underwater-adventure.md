# Underwater Adventure assets

Package: `incoming/underwater-adventure-v1.0.0.zip`
Schema: Voomi Template Schema 3.0.

Generated assets included in the package:

- `assets/images/background.jpg` - tropical reef background plate.
- `assets/frames/bubble-frame.png` - portrait card frame for replaceable user media.
- `assets/overlays/bubbles.png` - transparent edge bubbles, positioned clear of the portrait center.
- `assets/overlays/transition_wave.png` - transparent dive transition ripple.
- `assets/stickers/dolphin.png`
- `assets/stickers/turtle.png`
- `assets/stickers/fish_01.png` (clownfish)
- `assets/stickers/fish_02.png` (blue tang)
- `assets/stickers/yellow_fish.png`
- `assets/stickers/coral_cluster.png`
- `assets/stickers/starfish.png`
- `assets/stickers/treasure_chest.png`

The sticker art was generated as a transparent sprite sheet and separated into package assets. The package preview uses a generated sample selfie solely to show the composition; the sample selfie is not included as a template asset. Users provide two replaceable photo or video slots.

The template timeline is 12 seconds: selfie intro (0-2s), dive transition (2-5s), reef adventure (5-8s), and finale (8-12s). Layer motion uses the Schema 3.0 motion IDs and declared engine capabilities in `template.json`. No audio track is included.
